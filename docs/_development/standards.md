# Documentation Standards — the canon

**Type**: Spec
**Status**: current
**Last Verified**: 2026-08-06

The rules every doc in `docs/` follows. One closed doc-type taxonomy, one identity
block, one naming scheme, one living-vs-generated rule — all machine-checkable by
`scripts/doc_audit.py`. Philosophy: **no boilerplate, no one-size-fits-all; every doc
serves humans and AI agents equally.** Model: the modular docs surface of a sibling lab
project, stripped of its toolchain dependencies.

## 1. Doc-type taxonomy (closed `Type` enum)

Every hand-written doc declares exactly one `Type`. Adding a type means editing this list
and `doc_audit.py`.

| Type | For | Home | Template |
|------|-----|------|----------|
| `Spec` | authoritative standards that define how the repo works | `docs/specs/`, this file | `templates/template-spec.md` |
| `Guide` | living how-tos (pipeline, dev workflows, contributing) | `docs/guides/` | `templates/template-guide.md` |
| `Library Index` | per-library hub cataloguing its skills + graph + bridges | `docs/libraries/<lib>/index.md` | `templates/template-library-index.md` |
| `ADR` | architecture decision record (append-only) | `docs/adr/` | `templates/template-adr.md` |
| `Audit` | dated, evidence-backed audit/QA record | `docs/audit/` | `templates/template-audit.md` |
| `Narrative` | case study / story prose | `docs/narrative/` | — (prose) |
| `Generated` | machine-produced; never hand-edited | `docs/reference/`, `docs/libraries/<lib>/index.md` | — (owned by a script) |

## 2. Identity block + footer (mandatory on hand-written docs)

The first lines after the H1 title (a footer echo is optional; `**Last Verified**` is the
authoritative freshness field):

```markdown
# <Title>

**Type**: Guide
**Status**: current          <!-- current | draft | stale | superseded | historical -->
**Last Verified**: 2026-08-06

… body …

*Last verified against the repo: 2026-08-06.*
```

**Type-specific extras** (added to the identity block):
- `Library Index` also carries: `**Library**`, `**Domain**`, `**Source**: <org>/<repo>@<commit>`, `**Graph**: <N> nodes · <E> edges`.
- `ADR` also carries: `**ADR**: ADR-000N`, `**Date**`, and `**Status**` uses the ADR lifecycle (`proposed | accepted | superseded-by: ADR-000M`).
- `Audit` also carries: `**Date**` and a one-line `**Verdict**`.

**`Generated` docs** carry a banner instead of an identity block and are never hand-edited:
```markdown
<!-- generated by scripts/<name>.py — do not edit; regenerate to update -->
```

## 3. Naming & location

- **Folders** are `index.md`-homed (mkdocs-ready); a folder's `index.md` is a `Library Index`
  or a hub. Sub-domains nest as the content nests.
- **Specs**: `UPPER_SNAKE.md` (`SKILL_SPEC.md`, `GRAPH_SPEC.md`) — established, high-signal.
- **Guides / narrative**: `lower-kebab.md` (`methodology.md`, `before-after.md`).
- **ADRs**: `ADR-<4-digit>-<kebab-slug>.md` (`ADR-0001-one-skill-template.md`).
- **Audits**: `<topic>-audit-<YYYY-MM-DD>.md`.
- **Generated**: named by their producer; `lower-kebab.md` or `<lib>` folders.

The old signal "UPPER_SNAKE ⇒ hand-maintained" is retired — `Type`/`Status` in the identity
block is the source of truth, not the casing. (This is why the generated cross-library index
moved to `docs/reference/unified-index.md`.)

## 4. Living vs generated

- **Living** docs are hand-written and carry an identity block. Only humans/agents edit them.
- **Generated** docs are produced by a named script and carry the banner in §2. Editing them
  by hand is a lint failure — change the generator, then regenerate. Generators and their
  outputs:

  | Output | Producer |
  |--------|----------|
  | `docs/reference/unified-index.md` | `scripts/build_unified_index.py` |
  | `docs/reference/cross-library-bridges.json` | `scripts/inject_cross_edges_v2.py` |
  | `docs/reference/skill-validation-report.json` | `scripts/validate_skills.py` |
  | `docs/reference/edge-audits/edge-audit-<lib>.md` | `scripts/audit_edges.py` |
  | `docs/libraries/<lib>/index.md` | `scripts/build_library_docs.py` |
  | `docs/_development/doc_inventory.yaml` | `scripts/doc_audit.py --write` |

## 5. Lifecycle

- `current` → `stale` (footer date fell behind a referenced source) → refresh, or
- `current` → `superseded` (move to `docs/archive/`, add a pointer in `docs/archive/README.md`).
- ADRs are **append-only**: `proposed → accepted → superseded-by: ADR-000M`. Never edit a
  decided ADR's decision; write a new one that supersedes it. An ADR that is not in the
  `docs/adr/README.md` index does not exist.

## 6. Enforcement — `scripts/doc_audit.py`

`python scripts/doc_audit.py --ci` is the gate (CI `docs-audit` job). It fails on:
1. a hand-written doc missing a valid identity block or with a `Type` outside the enum;
2. a **dangling link** — any `](path)` to a repo file that does not exist;
3. `doc_inventory.yaml` out of sync with what is on disk;
4. a **stale** doc — `**Last Verified**` older than a referenced source (informational unless `--strict`).

`--write` regenerates `doc_inventory.yaml` (the census) from the identity blocks on disk.

## 7. Templates

The closed set lives in `templates/`. Start every new doc by copying the matching one:
`template-spec.md`, `template-guide.md`, `template-library-index.md`, `template-adr.md`,
`template-audit.md`. See `templates/README.md`.
