# ADR-0008: API-surface reconciliation for language-invisible symbols

**Type**: ADR
**ADR**: ADR-0008
**Status**: accepted
**Date**: 2026-08-12
**Last Verified**: 2026-08-12

## Context

The numpy graph (and any C-heavy library) is structurally unable to represent part of its own
public API. Verified 2026-08-12: 199 of 499 top-level `numpy` symbols are absent from the
committed graph — whole Cython modules (`random/_generator.pyx` — no tree-sitter grammar),
C-only ufuncs/builtins (`arange`, `abs`, `sin`, `dtype` — no Python `def` exists), and a few
Python-def'd symbols extraction missed (`array2string` in a known file). Re-extraction at the
pin cannot fix M1/M2 — the source never yields a parseable `def`. Worse, the citation gate only
checked citations that *exist*: an uncited gap like `arange` was invisible to every check.

## Decision

- **Mechanism — curated manifest.** `tools/curated/<lib>.json` (generated by
  `scripts/api_surface_diff.py --manifest`, reviewed before apply) pins one curated node per
  language-invisible symbol: real semantic description, truthful `source_file` (the module
  where the symbol is bound), joined to that module via a CURATED `contains` link (the
  `_cross_library` overlay precedent). `scripts/inject_curated_nodes.py` applies the manifest.
- **No re-extraction for these symbols** — curated-path is authoritative; the graph's
  extraction provenance (GRAPH_REPORT / `built_from_commit`) stays intact.
- **Spec — GRAPH_SPEC §5 gains criterion c6 "API-surface coverage"**: ≥95% of public top-level
  symbols must resolve (node | manifest | documented exclusion); `api_surface_diff.py` measures,
  `verify_citations.py --require-complete <lib>` enforces on every Quick Reference row.
- **Enforcement is per-library, opt-in** — numpy first; other libraries get the probe + manifest
  in follow-up waves (their gaps are expected to be smaller, pure-Python stacks).

## Consequences

- `arange`, `sin`, `dtype`, `Generator`-class surfaces etc. become citable and verifiable;
  the numpy graph grows to 8303 nodes with 100% top-level coverage.
- `graph_gate.py` reports gain a c6 row; gate reports regenerate with it.
- Bundles (ADR-0007) automatically carry curated nodes (they are part of graph.json).
- Skills' Quick Reference rows are now complete-checked: a `—` or unresolvable symbol is a CI
  failure, not a documented note.
- Follow-ups: run the probe for the remaining 10 libraries; fold the probe step into the
  onboarding playbook (QKG_018 F8).

## Alternatives considered

- Re-extract numpy at a new pin — cannot produce M1/M2 nodes (no grammar, no `def`); would
  invalidate all numpy hashes/descriptions for zero coverage gain.
- Hand-write a few skill citations without graph nodes — breaks the resolvability contract;
  curated nodes keep citations resolvable.
