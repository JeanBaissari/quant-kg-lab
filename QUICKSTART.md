# QUICKSTART -- Consume the quant knowledge base in 2 minutes

**Type**: Guide
**Status**: current
**Last Verified**: 2026-08-17

quant-kg-lab is a gold-standard knowledge base: **28 library knowledge graphs** (92K nodes /
230K edges) distilled into **142 spec-normalized skills** (27 routers, 97 modules, 18
cross-library playbooks) plus **71 curated cross-library bridges** (1,207 citations, 0
dangling -- all 28 libraries gate-green). Every citation traces to a graph node
(`source_file:line`) and every API claim is validated against the live library in CI.

You do **not** need graphify, a clone of upstream repos, or a network to consume it.

## Install

The `qkg` CLI (`scripts/qkg.py`) is the primary consumption path. No packaging step required.

### Quick: copy a skill (30 seconds)

```bash
# CLI (recommended)
python3 scripts/qkg.py install scipy --target ~/.claude/skills

# Manual: copy directly
cp -r skills/scipy/stats ~/.claude/skills/scipy-stats
```

Browse what is available in the [unified index](docs/reference/unified-index.md).

### Release bundles (from a GitHub Release)

Every tag ships versioned bundles (ADR-0007). Download from **Releases**:

```bash
# Graphs
unzip qkg-scipy.zip
#    -> scipy/graph.json + scipy/GRAPH_REPORT.md + scipy/.graphify_labels.json

# Skills tarball
unzip qkg-skills.zip && unzip qkg-quant-patterns.zip
#    -> skills/<lib>/<module>/SKILL.md  (copy-in layout)
```

Verify a bundle's integrity with the consumer contract (QKG_053):

```bash
curl -O https://raw.githubusercontent.com/JeanBaissari/quant-kg-lab/main/scripts/validate_bundle.py
python3 validate_bundle.py .           # full release dir
python3 validate_bundle.py . scipy     # single library
```

## Validate

```bash
# qkg CLI (recommended)
python3 scripts/qkg.py validate              # all libraries, lint only
python3 scripts/qkg.py validate scipy        # one library
python3 scripts/qkg.py validate --scores     # include quality scores

# Manual scripts
python3 scripts/validate_skills.py --ci      # lint, exit 1 on error
python3 scripts/validate_skills.py --strict  # also gate on API failures
python3 scripts/verify_citations.py          # all citations resolve
```

TA-Lib needs the system C library (`apt/brew install ta-lib`) before `pip install TA-Lib`.
The skill lint still runs without it.

## Search

```bash
# qkg CLI (cross-library BM25 search)
python3 scripts/qkg.py search kolmogorov smirnov

# Direct: single library
python3 scripts/query_graph.py scipy "kolmogorov smirnov"

# Direct: cross-library with score filter
python3 scripts/query_graph.py --all --min-score 2.0 "portfolio optimization"

# Graph exploration
python3 scripts/query_graph.py scipy "norm" --explain    # single node detail
python3 scripts/query_graph.py --all --path scipy pandas "optimization"  # find path
```

## Freshness

```bash
python3 scripts/qkg.py freshness          # compare pins to upstream HEAD
python3 scripts/check_freshness.py --ci   # exit 1 if any pin is stale
```

## What you get

| Layer | Contents |
|-------|----------|
| Graphs | 28 libraries pinned in `graphs.lock`, all passing the GRAPH_SPEC quality gate |
| Skills | 142 `SKILL.md` -- 27 routers + 97 modules + 18 playbooks |
| Citations | 1,207 checked, 0 dangling |
| Bridges | 71 curated cross-library edges (overlay graph) |
| CI gates | provenance, quality-gate, citations, doc audit, artifact safety |

Headline counts are generated by `scripts/emit_counts.py` and CI-diffed -- the numbers
cannot drift from `docs/reference/truth-counts.json`.

## Building a bundle yourself

```bash
python3 scripts/export_bundle.py --lib all --out dist --tag local
python3 scripts/check_artifact_safety.py --include-dist
```

## Troubleshooting

1. **TA-Lib validation** needs the system C library (`apt/brew install ta-lib`) before
   `pip install TA-Lib` -- the skill lint still runs without it.
2. **Skills are copy-in, not a package** -- no `pip install`; copy the directory.
3. **Bundles are not upstream source** -- graphs are extracted at pinned commits; `repo/`
   clones are gitignored and never shipped.
